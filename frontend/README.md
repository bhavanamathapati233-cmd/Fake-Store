# 🛒 Fake-Store

A modern full-stack e-commerce web application built with **React**, **Django**, and the **Fake Store API**. The application provides a clean and responsive shopping experience where users can browse products, search items, view detailed product information, and manage their shopping cart.

---

## ✨ Features

- 🛍️ Browse products
- 🔍 Search products
- 📂 Filter by categories
- 📄 Product details page
- 🛒 Shopping cart
- 📱 Fully responsive design
- ⚡ Fast and interactive user interface
- 🔗 API integration using Fake Store API
